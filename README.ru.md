# Anker Prime для macOS

[English documentation](README.en.md)

Неофициальное автономное приложение для управления **Anker Prime A2345 — 250 Вт, 6 USB-портов**. Оно напрямую подключается к облаку Anker. **Приложение работает только при подключении зарядки по Wi-Fi с доступом в интернет.**

Приложение объединяет показания портов, управление зарядкой, таймеры, расписания и историю в одном компактном окне. Светлая тема Anker включена по умолчанию. Интерфейс поддерживает русский и английский языки.

## Скачать и установить

Готовый установочный файл находится в разделе **[Releases](https://github.com/edsallo/anker-prime-macos/releases/latest)**: `Anker-Prime-macOS-Apple-Silicon.dmg`.

### Требования

- Mac с процессором **Apple Silicon**: M1, M2, M3 и последующие. Готовая сборка не предназначена для Intel.
- **macOS 14 Sonoma или новее**.
- Anker Prime **A2345**, добавленная в ваш аккаунт в оригинальном приложении Anker и подключённая к Wi-Fi с доступом в интернет.
- Аккаунт Anker с электронной почтой и паролем.

Отдельно устанавливать Node.js, Python или инструменты разработки для готового DMG **не нужно**.

### Установка с нуля

1. Откройте страницу Releases по ссылке выше.
2. В блоке Assets скачайте файл `.dmg`.
3. Дважды щёлкните скачанный файл.
4. В открывшемся диске перетащите **Anker Prime.app** на ярлык **Applications / Программы**.
5. Дождитесь копирования и извлеките диск Anker Prime через Finder.
6. Откройте **Программы → Anker Prime**.

Сборка имеет локальную подпись, но **не прошла заверение Apple (notarization)**. macOS может заблокировать первый запуск. Только если файл скачан из этого репозитория и вы доверяете ему: после попытки открытия найдите приложение в **Системные настройки → Конфиденциальность и безопасность** и воспользуйтесь предложенным macOS разрешением открытия. Названия элементов зависят от версии системы. Отключать Gatekeeper целиком не требуется.

### Первое подключение

1. Укажите email и пароль **аккаунта Anker**, используемого в приложении на телефоне.
2. Выберите регион облака и страну регистрации аккаунта.
3. Нажмите «Подключить зарядку».
4. Дождитесь появления станции и состояния «На связи».

Пароль не встроен в приложение. Если станция не найдена, проверьте аккаунт, регион, страну и её доступность в оригинальном приложении. Вход через Apple/Google без отдельного пароля напрямую не реализован.

## Возможности

| Раздел | Что доступно |
|---|---|
| Порты | Мощность, напряжение и ток для C1–C4, A1 и A2; прочерки для отсутствующих электрических показаний |
| Питание | Включение и выключение C1–C4; общее управление A1 и A2 |
| Режимы | AI Power, приоритет подключения, два ноутбука, малая мощность и пользовательский режим |
| Лимиты | USB-C с шагом 5 Вт, ограничения портов и общий бюджет 250 Вт; автоматическое уменьшение других лимитов при нехватке бюджета |
| Профили | Создание, редактирование, удаление и применение до четырёх облачных профилей, общих с Anker |
| Таймеры | Выключение через заданное число минут, отмена, обратный отсчёт с секундами |
| Расписание | Недельное расписание включения и выключения по дням и времени |
| Энергия | Вт·ч после сброса, приблизительный эквивалент мА·ч при 3,7 В, отдельный сброс счётчиков |
| История | Графики мощности, напряжения и тока; энергия, пиковая мощность, время зарядки и покрытие данными за период |
| Станция | Яркость, скринсейвер, выключение экрана, формат и расписание часов, праздничное оформление, направление энкодера, приоритет портов |
| Экспериментальные функции | Максимальная совместимость, пользовательские профили и распознавание поддерживаемых устройств |
| Названия | Личное имя каждого порта; уточнение производителя и модели в локальной базе VID/PID |
| Оформление | Anker светлая, Мята, Океан, Графит и Песок |
| Язык | Автоматически по macOS; ручной выбор «Системный», «Русский» и «English» в настройках |

В A1/A2 отдельные измерения, но общий выключатель, лимит и счётчик. Возможность настройки зависит от прошивки и облачных функций Anker. Произвольное фиксированное напряжение и управление прошивкой не реализованы. Это не официальный USB-PD анализатор.

### Как считаются энергия и мА·ч

Накопительный счётчик рассчитывает **само приложение** по мощности USB и времени между свежими измерениями, используя среднее двух соседних показаний. Разрывы свыше 30 секунд и время, когда приложение выключено, не добавляются. Это оценка выходной энергии, а не потребления из розетки.

`мА·ч ≈ Вт·ч ÷ 3,7 × 1000`. Значение — эквивалент при условном напряжении батареи, **не измеренная ёмкость аккумулятора**. Потери кабеля, преобразователей телефона и расход энергии самим устройством не учтены. КПД сетевого блока повторно применять нельзя: USB-энергия уже измерена после его потерь.

### Распознавание устройств

Используется сочетание таблицы Anker, подтверждённых наблюдений VID/PID и пользовательских уточнений. VID/PID может определять серию, а не конкретный экземпляр. При отсутствии пригодного идентификатора модель не угадывается. Личное имя остаётся привязанным к порту. Названия устройств и профилей не переводятся автоматически.

## Данные и работа приложения

Данные находятся в `~/Library/Application Support/Anker Prime`: зашифрованный аккаунт, ключ, счётчики, локальная база моделей и история. Настройки языка и темы сохраняются в предпочтениях macOS.

Ключ шифрования находится на том же Mac: это защита от хранения пароля открытым текстом, а не защита от доступа к вашему пользовательскому аккаунту. Не публикуйте содержимое папки данных.

Встроенная служба слушает только `127.0.0.1` на свободном порту, требует секрет текущего запуска и не открывается в локальную сеть. Облачное соединение требует интернета. При выходе из приложения сбор истории и энергии прекращается. Таймеры и расписания, уже переданные станции, продолжают выполняться самой станцией.

Для обновления закройте приложение и замените его новой копией из DMG. Локальные данные сохраняются. Для удаления перенесите приложение в корзину; папка данных остаётся отдельно. Её удаление уничтожит локальную историю, счётчики и сохранённый аккаунт.

## Сборка из исходников

Исходники ядра включены в `backend/`; соседний репозиторий не нужен. Требуются Apple Silicon, macOS 14+, Python 3, Node.js 22+ с npm и Xcode Command Line Tools.

```sh
xcode-select --install
git clone https://github.com/edsallo/anker-prime-macos.git
cd anker-prime-macos
npm ci --prefix backend
python3 build.py
node --test test/desktop.test.js
npm test --prefix backend
python3 create-dmg.py
```

`build.py` берёт Node из PATH; при необходимости задайте `NODE_BINARY=/полный/путь/к/node`. Сборка включает этот Node в приложение, компилирует Swift-оболочку для arm64 и подписывает её локальной подписью. Результат: `dist/Anker Prime.app`. `create-dmg.py` создаёт DMG с приложением и ярлыком Applications. Подпись Developer ID и notarization требуют отдельной учётной записи Apple Developer и в проекте не настроены.

## Структура

- `src/AnkerPrime.swift` — окно AppKit/WKWebView, запуск службы, настройки языка и темы.
- `src/desktop-server.js` — изолированная локальная сессия.
- `src/appearance/` — оформление, компактная компоновка и перевод интерфейса.
- `backend/` — автономное ядро, облачный протокол, интерфейс, история и тесты.
- `build.py`, `create-dmg.py` — сборка приложения и установочного образа.
